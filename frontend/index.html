    数据管理

    您的全部数据都保存在本机。这里可以导出备份，或一次性删除全部数据。

    导出全部数据

    下载 JSON 文件，包含身体数据、饮食与运动记录、报告与配置（不含 API Key 明文）。

    清除全部数据

    删除本机全部身体数据、记录与报告，此操作不可撤销。

    撤回隐私政策同意

    撤回后将返回同意页并停止使用应用，本机数据不会被自动删除。

    关于

    热量与代谢数值由程序计算或 AI 估算，可能存在误差，不构成医疗建议。
